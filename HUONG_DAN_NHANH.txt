🎬 HƯỚNG DẪN CÀI ĐẶT NHANH (MAC FILE BOT)
==================================================================

⚠️ 2 ĐIỀU KIỆN QUAN TRỌNG TRƯỚC KHI DÙNG:
   1. Cài ứng dụng Google Drive trên máy Mac:
      👉 Tải tại: https://www.google.com/drive/download/
      (Đăng nhập tài khoản Google của bạn sau khi cài).
   2. Chống máy ngủ (Sleep) để bot nhận lệnh 24/7 từ xa:
      • Vào Cài đặt hệ thống ➔ Màn hình (Displays) ➔ Nâng cao (Advanced)
        ➔ Bật "Ngăn chặn tự động chuyển sang chế độ ngủ khi màn hình tắt".
      • Hoặc cài app miễn phí "Amphetamine" trên Mac App Store.

1. CHUẨN BỊ TRƯỚC KHI CÀI:
   • Mã Bot Token Telegram (Lấy từ @BotFather trên Telegram).
   • Mã Gemini API Key (Lấy miễn phí tại: https://aistudio.google.com/apikey).
   (Chi tiết từng bước kèm ảnh xem file README.md)

2. CÀI ĐẶT TRONG 10 GIÂY:
   • Bấm đúp chuột vào file: CaiDat.command
   • Dán Bot Token và Gemini API Key theo hướng dẫn trên màn hình.

3. KÍCH HOẠT:
   • Mở Telegram, tìm con bot bạn vừa tạo và gửi: /start
   • Bot sẽ tự động nhận diện bạn là CHỦ NHÂN DUY NHẤT!
   • 💡 NẾU GỬI /start KHÔNG THẤY TRẢ LỜI:
     Bấm đúp vào file "KiemTraLoi.command" để kiểm tra lỗi và chạy trực tiếp!

4. NẾU DÙNG TÍNH NĂNG GỬI ZALO TỰ ĐỘNG:
   • Vào Cài đặt hệ thống ➔ Quyền riêng tư & Bảo mật ➔ Trợ năng (Accessibility)
     ➔ Gạt bật cho Python.
   • Đảm bảo ứng dụng Zalo trên máy Mac đang mở và đã đăng nhập.
